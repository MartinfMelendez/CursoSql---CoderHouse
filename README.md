# Curso SQL CoderHouse

# Proyecto Base de Datos
Este proyecto contiene un script SQL para crear y configurar una base de datos utilizando PostgreSQL.

# Requisitos
PostgreSQL instalado.

DBeaver instalado.

Acceso a una base de datos PostgreSQL.

# Cómo ejecutar el script
Abrir DBeaver.

Conectarse al servidor de PostgreSQL.

Crear una base de datos nueva o seleccionar una base de datos existente.

Abrir el archivo script.sql desde DBeaver.

Verificar que la conexión seleccionada corresponda a la base de datos donde se desea ejecutar el script.

Ejecutar el script completo utilizando el botón Execute SQL Script o presionando Alt + X.

Una vez finalizada la ejecución, actualizar el esquema de la base de datos para comprobar que las tablas y demás objetos fueron creados correctamente.

#Contenido del script
El archivo script.sql contiene todo lo necesario para configurar la base de datos, incluyendo:

Creación de la base de datos.

Creación de tablas.

Definición de claves primarias y foráneas.

Inserción de datos.

Consultas, modificaciones y eliminación de datos.
